# StepCore

**Шагомер для Android, который работает полностью офлайн и учится твоей походке.**

Без интернета. Без рекламы. Без аккаунта. Без аналитики. Ничего не уходит с телефона — это не обещание, а свойство сборки.

---

## Проверь сам за десять секунд

В манифесте приложения **нет разрешения `INTERNET`**:

[`app/src/main/AndroidManifest.xml`](app/src/main/AndroidManifest.xml)

Без этого разрешения Android физически не даёт приложению открыть сетевое соединение. Не «мы не собираем данные», а «мы не можем их отправить, даже если бы захотели».

Полный список того, что приложение просит, и зачем:

| Разрешение | Зачем |
|---|---|
| `ACTIVITY_RECOGNITION` | доступ к шагомеру-чипу — он и считает шаги |
| `HIGH_SAMPLING_RATE_SENSORS` | акселерометр с частотой, достаточной для разбора походки |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_HEALTH`, `WAKE_LOCK` | счёт продолжается с выключенным экраном; тип «health» — требование Android для фоновых сервисов, связанных с активностью |
| `POST_NOTIFICATIONS` | уведомление работающего счётчика |
| `VIBRATE` | тактильный отклик на калибровке |
| `ACCESS_FINE_LOCATION` | **только** для измерения длины шага по GPS, по явному нажатию. Маршруты не пишутся, фоновой геолокации нет |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | чтобы система не убивала счётчик на длинной прогулке |

## Что внутри

**Шаги считает аппаратный чип** (`TYPE_STEP_COUNTER`), а не алгоритм поверх акселерометра. Чип работает независимо от приложения и переживает его выгрузку из памяти. Акселерометр нужен для другого: отличить ходьбу от бега, поймать тряску, разобрать характер движения.

**Приложение учится конкретному человеку.** Оно замечает, как ты идёшь в гору и с горы, спрашивает подтверждения и постепенно перестаёт спрашивать. Модель влияет на интерпретацию — метки, длину шага, калории — и **никогда** на сам счёт шагов. Ошибка обучения портит подсказку, а не статистику.

**Пороги выведены из измерений.** В коде рядом с каждой константой стоит комментарий, откуда взялось число. Например, порог различения бега и ходьбы — середина измеренного зазора амплитуд, а не круглое значение из головы.

**Калибровка вместо таблиц.** Длина шага измеряется на размеченном отрезке по GPS, темп ходьбы и бега — на реальной прогулке. Пока не измерено — приложение честно говорит, что использует оценку по росту.

Отдельно есть **Экспедиция** — офлайн-симуляция мира, которую двигают реальные шаги. Помечена как BETA и развивается медленно.

## Установка

Готового APK в магазинах нет. Собирается из исходников через GitHub Actions: вкладка **Actions** → последняя успешная сборка → артефакт `stepcore-apk`.

**Требуется Android 11 (API 30) или новее.** На более старых устройствах не установится.

Отдельно про MIUI и HyperOS: система агрессивно душит фоновую работу, и без настроек счёт будет прерываться. Что именно включить — в [MIUI_SETUP.md](MIUI_SETUP.md).

## Нужны тестировщики

Приложение написано и проверено на **одном** телефоне: Xiaomi 13T Pro, HyperOS. Как оно ведёт себя на Samsung, Pixel, Nothing и прочих — неизвестно. Купить парк устройств для тестов возможности нет.

Поэтому предложение честное: приложение бесплатное и таким останется, а взамен полезен отчёт с твоего телефона.

**Что особенно интересно:**

- переживает ли счёт агрессивное «убийство» фоновых процессов (Samsung, Huawei, Oppo, Xiaomi);
- сходится ли счёт с системным шагомером за день;
- расход батареи за сутки;
- всё, что выглядит сломанным или непонятным.

**Как сообщить:** вкладка [Issues](../../issues). Внутри приложения есть кнопки экспорта диагностики и данных — файл из них помогает больше, чем описание словами.

Модель телефона, версию Android и оболочку укажи обязательно: почти все различия в поведении идут именно оттуда.

## Разработка

Проект развивается небольшими релизами: одно изменение — одна забота. Каждое проверяется на записанных реальных прогулках, а не на синтетике. Если новая версия улучшает один сценарий и ухудшает другой — она не принимается.

Ключевое правило: **ядро счёта меняется только по собранным данным.** Гипотеза без измерения — не основание трогать то, что работает.

Разработка ведётся с телефона, в Termux. Сборка — GitHub Actions.
